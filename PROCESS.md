# AI-Supported Development Process

## Initial Idea

The goal of this project was to build an AI-supported educational legal assistant for university students.

## AI Tools Used

- ChatGPT (GPT-5.5)
- GitHub

## Development Steps

1. Defined the project idea.
2. Created the repository on GitHub.
3. Generated the README documentation.
4. Planned the website structure.
5. Created the project files.
6. Reviewed and improved the generated content.

## Prompt Examples

- Create a README for an AI legal assistant.
- Explain legal concepts in simple language.
- Generate a simple educational website.

## Problems Encountered

- Organizing the repository structure.
- Learning how GitHub works.
- Improving AI-generated content.

## Human Contribution

The project idea, testing, review, and final decisions were made by the author.

## Lessons Learned

This project demonstrated that AI can significantly accelerate software development, but human review is essential to verify correctness and improve quality.
